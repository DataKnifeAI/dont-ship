## Logo — Fen (cute non-humanoid wolf)

Fen as logo is mid-century corporate-cute: gray-brown wolf, cream muzzle, soft friendly eyes — a normal wolf (sitting four-legged or simple head/bust), avocado/harvest/burnt-orange/cream/IBM-blue palette. Good as GitHub avatar, favicon, and bottom-left footer seal on posters (not top-right).

**Do not** use bipedal / necktie / standing-courier Fen as the primary logo.

**Slogan (fiction):** “Outcomes in the pack. Timelines optional.”

## Herographic + boss NPC — Wally (stork)

Wally is the **herographic hero** and **Dock Supervisor NPC**: tired mid-century airline-ad stork, cream plumage, harvest-gold necktie, IBM-blue badge, clipboard as management weapon. Cheerful corporate posture over exhausted eyes — Box 407-B’s mid-level dock boss.

**Slogan:** “The J.E.V. says… outcomes first.”  
**Catchphrases (tone):** performance reviews, “per policy,” “Box 407-B is watching,” “timelines are a suggestion.”

Primary widescreen banner features **Wally** (like the original stork herographic), title **D.O.N.T. Ship** (singular) + tagline **Delivering Outcomes, Not Timelines.** Small Fen wolf seal in the **bottom-left** footer only — no top-right Fen mark. Wally remains the graphic hero.
